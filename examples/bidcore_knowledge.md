# BidCore Demo Knowledge Base

## Security

Xelqara demo service encrypts customer data at rest and in transit. Multi-factor authentication is available for administrative accounts. These statements are demo claims only and require customer verification before use in a real proposal.

## Compliance

The demo organization maintains an internal security policy and reviews access permissions periodically. No external certification or regulatory claim should be inferred from this document.

## Implementation

The demo service can be deployed in a private environment. Deployment timelines and service levels must be confirmed by an authorized team member.
